¿Qué es HTML?

Definición: HTML (HyperText Markup Language) es el lenguaje base que se utiliza para la creación de páginas web.

HTML es un lenguaje de marcado cuyo estándar lo define la W3C (World Wide Web Consortium) y actualmente HTML se encuentra en su versión HTML5.

¿Que significa HTML?

HTML significa "Lenguaje de Marcado de Hypertexto" por sus siglas en ingles "HyperText Markup Language".

Es un lenguaje que pertenece a la familia de los "lenguajes de marcado" y tiene la capacidad de enlazar documentos o páginas entre sí gracias al Hypertexto (mejor conocido como links o enlaces).

¿Por qué HTML no es un lenguaje de programación?

Mucha gente cree que HTML es un lenguaje de programación, pero NO, el código HTML no es un lenguaje de programación ya que no cuenta con funciones aritméticas, variables o estructuras de control propias de los lenguajes de programación. HTML es estático y descriptivo, por lo que con HTML podemos crear únicamente páginas web o documentos estáticos con links, sin embargo, HTML se puede usar en conjunto con diversos lenguajes de programación para la creación de páginas web dinámicas que realicen tareas muy complejas.

¿Para qué sirve HTML?

Ya lo dijimos antes: HTML sirve para crear páginas web, pero, ¿Cómo lo hace?.

Pues básicamente el lenguaje HTML sirve para definir y describir la estructura de una página y sus elementos, organiza la forma en que se mostrará el contenido por medio de etiquetas con las cuales se puede describir todo el contenido de la página como por ejemplo el texto, imágenes, enlaces, videos, entre otros, de modo que es HTML el encargado de estructurar (hasta cierto punto) la apariencia que tendrá la página web.

¿Que son las etiquetas HTML?

Las etiquetas HTML son fragmentos de texto rodeados por corchetes angulares < > que se utilizan para escribir código del lenguaje HTML.

En HTML existen etiquetas de apertura y etiquetas de cierre, tienen la forma: <etiqueta> </etiqueta>. Donde <etiqueta> es la etiqueta de apertura y </etiqueta> es la etiqueta de cierre indicada por la diagonal. HTML tiene definidas gran variedad de etiquetas para distintos usos.

Por ejemplo la etiqueta <p> indica el inicio de un párrafo el cual terminaría al encontrar la etiqueta de cierre </p>.

Las etiquetas HTML no se muestran al usuario que visualiza una página, las etiquetas son instrucciones para el navegador web quien funciona como intérprete de todo nuestro código HTML para que éste convierta el código en algo visual.

¿Qué es un documento HTML?

Para desarrollar una página web en HTML es necesario crear un documento HTML. Básicamente un documento HTML es un archivo de texto que tienen la extensión .html o .htm, en este documento se escriben todo el texto y las etiquetas HTML necesarias para la creación de una página, al texto escrito en el documento HTML se le llama código HTML. Un documento HTML se puede generar con cualquier editor de textos simple como el bloc de notas de Windows o Gedit de Linux.

¿Qué es HTML5?

HTML5 es la última versión o estándar del lenguaje HTML.

En pocas palabras HTML5 es el mismo lenguaje HTML de toda la vida pero con algunas novedades y etiquetas extra.

Destacan el uso de etiquetas semánticas y su mayor compatibilidad con contenidos multimedia.
