Introducción al Manual de HTML

Este es el primer post del manual de HTML, trataremos conceptos básicos sobre la importancia del lenguaje HTML en Internet y la diferencia entre una página web y un sitio web, espero les sea de ayuda para aprender el lenguaje HTML.

Internet funciona con HTML

Sin duda alguna Internet es un gran invento, un invento que ha cambiado el estilo de vida de millones de personas alrededor de todo el mundo, un invento que ha revolucionado completamente la forma de comunicarnos, de hacer negocios, de aprender, de divertirnos, en fin la forma de interactuar con el mundo en general, es por eso que Internet es uno de los inventos mas importantes de los últimos tiempos.

Como todo gran invento, detrás de Internet hay un sin fin de tecnologías, en este manual nos centraremos a tratar una en particular llamada HTML, la tecnología que es base de cualquier sitio web.

Si alguien me preguntara de que esta hecha una página web mi respuesta sería: HTML.

Todas las páginas web utilizan HTML es por eso que cualquier persona interesada en la creación de páginas web debería comenzar por aprender el lenguaje HTML, es el primer paso para adentrarse a este interesante mundo.

Creo que está de más explicar "que es Internet" pues si estás leyendo esto creo que ya estás más que familiarizado y seguramente habrás visitado un sin fin de sitios web. Lo que si me gustaría aclarar en este artículo son dos conceptos clave que generalmente se usan como sinónimos o de manera incorrecta, estos dos conceptos son: "página web" y "sitio web".

Página Web VS Sitio Web

Es muy simple de explicar, un sitio web está formado de varias páginas web, es decir un sitio web es como un libro completo y una página web es como una única página de ese libro, pero los libros se escriben una página a la vez del mismo modo un sitio web se escribe o codifica en HTML una página a la vez, así que en este manual aprenderemos a crear páginas web escribiendo código en HTML.

Que mas?, bueno la intención principal con este post introductorio es animarlo a continuar con la lectura de este Manual de HTML y así pueda conocer un poco mas esta "parte técnica" de Internet (si es que le interesa claro) y de esta forma pueda aprender a crear sus propias paginas web, espero que este sitio web le sea de gran utilidad.
