Comentarios en HTML

En todos los lenguajes de programación existe los llamados “comentarios” y HTML (aunque no es un lenguaje de programación sino un lenguaje de marcado) también hace uso de los comentarios.

Los comentarios son simples anotaciones escritas que solo pueden leerse directamente desde el código fuente, es decir, no se muestran en la parte visual de la página, son usados como anotaciones dirigidas al programador o editor lo cual permite que estos tenga una mayor comprensión del código, se podría decir que pueden usarse para "explicar" algunas partes del código o como notas personales o recordatorios.

Un comentario no tiene ningun efecto en el funcionamiento de una página web, esto debido a que los comentarios son dirigidos hacia la persona que los lee y no hacia la computadora, entonces, cuando el navegador interpreta el código HTML simplemente ignora todo el texto que esté contenido dentro de un comentario.

En HTML los comentarios pueden ocupar una o varias lineas, se escriben de la siguiente manera:

<!—- Esto es un comentario de una sola línea –->

<!—- Esto es un
comentario en
varias lineas –->

Un comentario en HTML inicia con <!-- y termina con --> todo lo que esté escrito después de <!-- será considerado como parte del comentario, inclusive se puede agregar código HTML o de cualquier otro lenguaje y será ignorado por el navegador hasta encontrar el cierre del comentario -->.

Veamos un ejemplo aplicado a una página:

<html>
<head>
<title>Prueba de comentarios HTML.</title>
</head>
<body>
<p>Este es un texto visible de la página.</p>
<!-- Este es un comentario HTML,
por lo tanto no será visible en el navegador,
<b>Inclusive</b> utilizo etiquetas HTML,<br>
pero no servirán de nada. -->
<p>Aquí continúa el texto de la página.</p>
</body>
</html>

El resultado sería el siguiente:

Este es un texto visible de la página.

Aquí continúa el texto de la página.

Podemos observar que en el resultado no se visualiza el comentario incluido.
