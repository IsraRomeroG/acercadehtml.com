Etiqueta applet

¿Para qué sirve?

La etiqueta <applet> sirve para incrustar en la página un applet de Java, sin embargo, esta etiqueta está obsoleta y ya no se deberá usar a partir de la versión HTML 5, en su lugar deberá usarse la etiqueta <object>.

¿Qué es un applet?

Un applet es un programa, componente o aplicación que se ejecuta dentro del contexto de otro programa o aplicación, por ejemplo un videojuego escrito en Java que se ejecuta en una página web desde un navegador como google Chrome o Firefox, ahí es donde entra en funcionamiento la etiqueta <applet>

En este ejemplo el navegador descarga y ejecuta el applet pero es necesario que el usuario tenga instalado Java y habilitada la ejecución de este tipo de programas, en caso contrario la página cargaría pero el applet no se ejecutaría al ser bloqueada por el navegador.

Ejemplo de uso:

<applet code=“mi_applet.class” width=“640” height=“480”> </applet>

En este ejemplo se inserta mi_applet.class indicada en el atributo code desplegado en pantalla con un ancho de 640x480 pixeles.

Atributos:

Los atributos obligatorios para esta etiqueta son code, width y height.

Atributo: code
Descripción: Especifica la ruta del applet que deseamos incrustar.
Valor: La ruta donde está nuestra applet.

Atributo: width
Descripción: Especifica el ancho del área donde se visualizará el applet.
Valor: Valor numérico del ancho.

Atributo: height
Descripción: Especifica el alto del área donde se visualizará el applet.
Valor: Valor numérico de la altura.

Además de los tributos mencionados esta etiqueta no tiene atributos específicos, sin embargo se pueden usar todos los atributos globales de HTML.
