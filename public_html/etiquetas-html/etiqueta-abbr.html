Etiqueta abbr

La etiqueta <abbr> sirve para indicar el significado de una palabra abreviada o las siglas de un término.

Esta etiqueta no tiene una utilidad funcional visible para los usuarios, pero en algunos navegadores se puede ver la función al pasar el puntero del mouse por la palabra etiquetada, resaltando el significado de la palabra, además esta etiqueta ayuda a que los buscadores entiendan mejor el contenido de la página.

Por ejemplo, si un artículo escribo acerca de HTML vendría bien utilizar esta etiqueta para decirle al navegador el significado de HTML (HyperText Markup Language).

Ejemplo de uso:

<abbr title="HyperText Markup Language">HTML</abbr>

Resultado:

HTML

En el ejemplo es evidente que la etiqueta <abbr> no produce ninguna afectación o alteración al texto, aunque algunos navegadores hacen resaltar el "title" de la etiqueta al pasar el cursor por encima de la palabra, en este caso si tu navegador tiene esta función se debería de ver el texto "HyperText Markup Language" al pasar el cursor por encima de la palabra "HTML" en el cuadro de resultado de nuestro ejemplo.

Resumidamente este es el uso de la etiqueta <abbr> ten por seguro que los usuarios tal vez no notarán o valorarán esta etiqueta, pero seguramente los buscadores si lo harán.
