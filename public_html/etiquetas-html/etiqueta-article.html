Etiqueta article

¿Para qué sirve?

La etiqueta article <article> forma parte del grupo de etiquetas semánticas de HTML5, no tiene una funcionalidad visual por sí sola, aunque se le puede agregar un estilo propio con CSS.

Su uso radica en definir un fragmento de contenido específico dentro de una página HTML, puede ser usada por ejemplo para definir un artículo, noticia, entrada de un blog, un comentario, un mensaje de un foro o cualquier fragmento de información independiente y relevante en la página.

La etiqueta <article> crea un contenedor o bloque al igual que la etiqueta <div>, la diferencia está en que la etiqueta <article> pertenece a las nuevas etiquetas semánticas de HTML5, esto hace que tenga la peculiaridad de dar información a los buscadores como google para que estos entiendan mejor la estructura de nuestro documento. En el caso de la etiqueta <article> le indica a los motores de búsqueda que el contenido definido entre esta etiqueta es información útil para el usuario final.

Sintaxis:

Para escribir la etiqueta article es necesario utilizar su etiqueta de cierre y etiqueta de apertura siempre, entre ambas etiquetas se puede escribir cualquier texto o código.
<article>
<!-- Cualquier contenido o código HTML -->
</article>

Ejemplo de uso:

<article>
<h2>Titulo de mi post</h2>
<p>Esto es un párrafo de ejemplo</p>
</article>

Resultado:

Titulo de mi post

Esto es un párrafo de ejemplo

Recomendaciones:

Se recomienda su uso para una mejor organización del contenido y para una mejor indexación en los principales motores de búsqueda.

Es una etiqueta reusable y (como mencionaba anteriormente) se puede complementar con CSS para darle un aspecto visual.

Atributos:

Esta etiqueta no tiene atributos específicos, sin embargo se pueden usar todos los atributos globales de HTML.
