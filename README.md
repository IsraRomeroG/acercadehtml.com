# Acerca de HTML

Sitio educativo sobre HTML construido con Astro. Conserva el contenido, las imágenes y las rutas `.html` del sitio original, con una interfaz adaptable a móviles.

## Comandos

| Comando | Acción |
| --- | --- |
| `npm install` | Instala las dependencias |
| `npm run dev` | Inicia el servidor local de Astro |
| `npm run build` | Genera el sitio estático en `dist/` |
| `npm run preview` | Previsualiza localmente el sitio generado |

El contenido de referencia permanece en `public_html/`. Las páginas Astro lo reutilizan con un diseño compartido; los recursos estáticos y la verificación del sitio se sirven desde `public/`.
